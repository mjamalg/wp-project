## This is the original version of the project that became Control Stack Lab

 I built this back in 2024 as a production-level AWS reference architecture: an EKS-based, highly available design provisioned with Terraform and Ansible, using WordPress as the demo workload running on top. It started as an interview project and became the foundation for something bigger.

 Since then, the project has been substantially modernized and expanded into **Control Stack Lab**, the current, fully updated, deploy-ready toolkit. The current version updates the entire stack to today's versions, adds an AI module built on AWS Bedrock, and includes a containerized workstation, complete architect's notes, AWS architecture diagrams, and step-by-step deployment guidance, all designed to help AWS Cloud/Infrastructure Engineers stand out in technical interviews.

 **This repo is preserved as the starting point. The architecture diagram and project overview are here to show what was built and why.**

 👉 The current, complete, supported version lives at **[controlstacklab.io](https://controlstacklab.io)**
